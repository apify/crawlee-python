Most crawls start from a handful of URLs and grow by following links discovered on the visited pages. This guide shows how to crawl a fixed list of URLs, how to enqueue newly discovered links with the <ApiLink to="class/EnqueueLinksFunction">`enqueue_links`</ApiLink> helper, and how to control which links end up in the <ApiLink to="class/RequestQueue">`RequestQueue`</ApiLink>.

## Crawling a list of URLs

The simplest case is crawling a known list of URLs. Pass the list to <ApiLink to="class/BasicCrawler#run">`crawler.run`</ApiLink> and the request handler is invoked for each of them.

## Crawling all links on a website

To crawl a whole website, call the <ApiLink to="class/EnqueueLinksFunction">`enqueue_links`</ApiLink> helper in the request handler. It finds the links on the current page and adds them to the <ApiLink to="class/RequestQueue">`RequestQueue`</ApiLink>, so the crawler systematically works through the site page by page.

:::tip

If no options are given, by default the method will only add links that are under the same hostname. This behavior can be controlled with the `strategy` option. For details, see [Enqueue strategies](#enqueue-strategies).

:::

## Crawling specific links

You'll often want to follow only links that match certain patterns. Pass the `include` or `exclude` parameters to <ApiLink to="class/EnqueueLinksFunction">`enqueue_links`</ApiLink> - both accept lists of globs or regular expressions - and only the matching links are added to the <ApiLink to="class/RequestQueue">`RequestQueue`</ApiLink>. This keeps the crawl focused on the relevant sections of a website and avoids scraping unnecessary content.

## Enqueue strategies

<ApiLink to="class/EnqueueLinksFunction">`enqueue_links`</ApiLink> automatically resolves relative links based on the page's context and decides which of them to follow according to the `strategy` option (the `EnqueueStrategy` type alias). Four strategies are available:

- `all` - Enqueues all links found, regardless of the domain they point to. Useful when you want to follow every link, including those that navigate to external websites.
- `same-domain` - Enqueues all links found that share the same domain name, including any possible subdomains.
- `same-hostname` - Enqueues all links found for the exact same hostname. This is the **default** strategy. It restricts the crawl to links with the same hostname as the current page and excludes subdomains.
- `same-origin` - Enqueues all links found that share the same origin - the same protocol, domain, and port - ensuring a strict scope for the crawl.

:::note

These examples use the <ApiLink to="class/BeautifulSoupCrawler">`BeautifulSoupCrawler`</ApiLink>, but the same method is available for all crawlers and works exactly the same way.

:::
