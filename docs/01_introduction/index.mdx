Crawlee for Python is a web scraping and browser automation library. It handles the crawling infrastructure for you: it queues and deduplicates requests, retries failures, scales concurrency to the available system resources, rotates proxies and sessions, and stores the results. You write the code that extracts the data.

The same interface works for plain HTTP crawling and for headless browsers, so you can switch between them without rewriting your handlers. With the default configuration, the HTTP client impersonates a real browser and browser crawlers use generated fingerprints, which helps them get past common bot protections.

## Features

- One interface for HTTP and headless browser crawling.
- Automatic parallel crawling based on available CPU and memory. For details, see [Scaling crawlers](./concepts/scaling-crawlers).
- Automatic retries on errors and when the crawler gets blocked. For details, see [Error handling](./concepts/error-handling).
- Proxy rotation and session management. For details, see [Proxy management](./concepts/proxy-management) and [Session management](./concepts/session-management).
- Request routing that sends each URL to the right handler. For details, see [Request router](./concepts/request-router).
- A persistent request queue and pluggable storages for tabular data and files. For details, see [Storages](./concepts/storages).
- Full type hint coverage, built on standard `asyncio`.

## Crawler types

Crawlee provides several crawlers that share the same base class, <ApiLink to="class/BasicCrawler">`BasicCrawler`</ApiLink>:

- <ApiLink to="class/BeautifulSoupCrawler">`BeautifulSoupCrawler`</ApiLink> and <ApiLink to="class/ParselCrawler">`ParselCrawler`</ApiLink> fetch pages over HTTP and parse the HTML. They're fast and light, but they can't run JavaScript. For details, see [HTTP crawlers](./concepts/http-crawlers).
- <ApiLink to="class/PlaywrightCrawler">`PlaywrightCrawler`</ApiLink> controls a headless browser through [Playwright](https://playwright.dev/), for pages that render their content with JavaScript. For details, see [Playwright crawler](./concepts/playwright-crawler).
- <ApiLink to="class/AdaptivePlaywrightCrawler">`AdaptivePlaywrightCrawler`</ApiLink> decides per request whether a plain HTTP fetch is enough or a browser is needed. For details, see [Adaptive Playwright crawler](./concepts/adaptive-playwright-crawler).
- <ApiLink to="class/PydanticAiCrawler">`PydanticAiCrawler`</ApiLink> and <ApiLink to="class/StagehandCrawler">`StagehandCrawler`</ApiLink> use an LLM to extract data or drive the browser. For details, see [Pydantic AI crawler](./concepts/pydantic-ai-crawler) and [Stagehand crawler](./concepts/stagehand-crawler).

## Installation

Crawlee requires Python 3.10 or higher. It's available as the [`crawlee`](https://pypi.org/project/crawlee/) package on PyPI. The core package is small, and each crawler type comes with an optional extra. To install Crawlee with all extras, run:

```sh
pip install 'crawlee[all]'
```

To use the <ApiLink to="class/PlaywrightCrawler">`PlaywrightCrawler`</ApiLink>, also install the browser binaries:

```sh
playwright install
```

For the list of extras and for bootstrapping a project from a template with the Crawlee CLI, see [Setting up](./introduction/setting-up).
